# 露營旅行規劃 Skill

透過分階段訪談整理需求，查核營地、價格、指定日期的空位與天氣，並依需要製作餐點計畫、手機版 HTML 或 PDF 旅行指南。本套件強調資訊來源、資料時效、真實照片，以及共享收藏功能的技術界線。

## 使用方式

Skill 位於 [`camping-trip-planner/`](camping-trip-planner/SKILL.md)。請依使用平台的官方安裝方式，將此資料夾放入該平台支援的 Skill 位置；不同助理的探索與呼叫機制不同，本儲存庫不會自行安裝，也不保證所有平台自動辨識。也可以直接把 `SKILL.md` 及相關參考文件提供給助理，作為工作指引。

最新營地研究需要可用的瀏覽工具；PDF 渲染、網站發布與共享資料庫則是選用能力，並非本套件附帶服務。本套件不設定帳號、未公開的業者 API、主機、訂位或付款功能。所有範例資料均為**合成測試資料**，不是實際營地推薦、價格或庫存；儲存庫不包含私人行程或來源照片。

### 範例提示詞

- 「請幫我比較六個適合三晚露營的營地，先分階段詢問還缺少的需求。」
- 「把我們選好的營地做成私人手機版指南和 PDF，包含最新訂位連結與有來源的真實照片。」
- 「我們四人只有一個爐具、沒有冰箱，請提供 12 種早餐與 12 種晚餐構想。」
- 「兩位參與者需要跨裝置保留與共享收藏，實作前請先說明資料儲存及存取權限方案。」

## 內容

- `SKILL.md`：主要流程與操作權限界線。
- `references/questionnaire.md`：繁體中文分階段標準訪談，已回答的問題不重複詢問。
- `references/research.md`：價格、空位、天氣與來源查核規則。
- `references/delivery.md`：手機版 HTML、PDF、真實照片／配置圖與收藏功能要求。
- `references/plan.schema.json`、`example-plan.json`：可攜式資料核心與合成範例。
- `scripts/`：資料一致性檢查與測試。

## 驗證資料核心

需要 Python 3.10 以上；下列檢查程式與測試僅使用標準函式庫：

```sh
python camping-trip-planner/scripts/validate_plan.py camping-trip-planner/references/example-plan.json
python camping-trip-planner/scripts/test_validate_plan.py
```

JSON Schema 定義資料結構；Python 程式檢查跨欄位日期、住宿晚數、價格與折扣算式、空位查詢證據欄位，以及營地和餐點數量。`minor_unit_digits` 表示幣別的小數精度，百分比折扣以該精度四捨五入；若業者採用不同進位政策，應另外建模，不要為符合檢查程式而修改業者報價。

**驗證通過不代表來源真實、價格有效或仍有空位**，也不代表已訂位。對外提供資訊前，仍須遵守研究規則並實際檢查成品。

## 隱私與發布

要求 HTML／PDF 不等於同意公開發布。公開網站、共享收藏服務、聯絡營地、傳送個資、訂位與付款，都必須先取得使用者相應指示及必要確認。瀏覽器本機收藏不是跨裝置同步；姓名／角色選單也不是登入驗證。
